# ALL VIDEO DOWNLOADER

واجهة عربية وخادم Node.js لتحليل روابط الفيديو العامة وتنزيل المحتوى المسموح به بصيغ MP4 أو MP3 مع اختيار الجودة ومعاينة الصورة المصغرة.

## التشغيل المحلي
يتطلب Node.js 22 وPython 3 وyt-dlp وFFmpeg.
1. `npm install`
2. `npm start`
3. افتح `http://localhost:3000`

## Railway
اربط المستودع بخدمة Railway. سيُكتشف Dockerfile تلقائياً ويُقرأ المنفذ من متغير `PORT`.

## تنبيهات
- لا يدعم DRM أو المحتوى الخاص/المقيد أو تجاوز تسجيل الدخول والحماية.
- استخدمه فقط للمحتوى الذي تملكه أو لديك إذن بتنزيله، مع احترام حقوق النشر وشروط المنصات.
- قبل الإطلاق العام أضف حدوداً لحجم/مدة التنزيل، مراقبة موارد، سياسة خصوصية وشروط استخدام.
- لا تضع مفاتيح أو كلمات مرور أو cookies في GitHub.
